# DBMS Syllabus

## Unit I — Overview of DBMS & the Relational Model
- **Database system architecture:** Data abstraction, data independence, DDL, DML.
- **Data models:** ER model, network model, relational and object-oriented models, integrity constraints, data manipulation operations.
- **ER model:** Entity set, relationship set, cardinality, types of entities, types of keys, aggregation, specialization, generalization.

## Unit II — Database Design (9 Lecture Hours)
- **Database design:** E-R diagrams, constraints, normal forms.
- **Relational algebra:** Fundamental & additional operations — select, project, Cartesian product, UNION, set difference, rename; types of joins, division, intersection, aggregate.
- Tuple and domain relational calculus, SQL3, DDL and DML constructs.
- Open source and commercial DBMS — MySQL, Oracle, DB2, SQL Server.

## Unit III — SQL & Relational Database Design (9 Lecture Hours)
- **SQL:** Data definition, data manipulation, queries, views, constraints, triggers.
- **Integrity:** Integrity constraint, domain constraint, referential integrity.
- **Functional dependencies:** Closure of set, cover and canonical cover, anomalies, Armstrong's axioms, extended Armstrong's axioms, assertions and demons.
- **Decomposition & normalization:** Domain and data dependency, normal forms (1NF, 2NF, 3NF, BCNF), dependency preservation, lossless design.
